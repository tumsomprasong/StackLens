## Reporting a Vulnerability

The StackLens team takes security and user privacy extremely seriously.

If you discover a security vulnerability or potential privacy leak in StackLens, please report it responsibly. **Do not disclose the issue in a public GitHub issue.**

### How to Report Privately:
1. **GitHub Private Vulnerability Reporting (Preferred)**:
   - Go to the **Security** tab of the [StackLens repository](https://github.com/tumsomprasong/StackLens/security).
   - Click **Report a vulnerability** to open an advisory draft accessible only to repository maintainers.
2. **Direct Contact**:
   - If Private Vulnerability Reporting is unavailable, reach out via the maintainer's GitHub profile: [github.com/tumsomprasong](https://github.com/tumsomprasong).

### Please Include in Your Report:
- A clear description of the vulnerability and its potential impact.
- Step-by-step reproduction instructions or a minimal Proof of Concept (PoC).
- Your browser name, version, and operating system.

### Our Response Commitment:
- We will acknowledge receipt of your report within **48 hours**.
- We will provide an assessment and targeted remediation timeline.
- Once patched, a new extension package will be published promptly to the Chrome Web Store and GitHub Releases, with credit given to the reporter (if desired).
