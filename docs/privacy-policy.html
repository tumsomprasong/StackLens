StackLens Privacy Policy

Effective Date: November 5, 2026 · Open-Source (GPL-3.0-only) · Chrome Web Store

Zero User Data Collection

1. Overview & Zero-Telemetry Commitment

StackLens is a 100% free, open-source, serverless Chrome Extension that identifies web technologies, DNS/IP infrastructure, known CVE library vulnerabilities, and publicly visible webpage metadata.

We do NOT collect, store, transmit, rent, or sell any personal data, browsing history, or user telemetry. StackLens operates without any proprietary backend server, analytics script, or user account system.

2. Local In-Browser Data Processing

  • DOM, Script, CSS & Header Inspection: StackLens inspects the active webpage's HTML, JavaScript globals, CSS variables, and HTTP response headers strictly within local browser memory against our bundled fingerprint rules (rules/technologies.json).
  • Cookie & SSO Metadata Inspection: StackLens checks cookie names and public JWT issuer (iss) claims locally to identify authentication systems (such as Keycloak, NextAuth.js, or Microsoft Entra ID). Raw cookie secrets, session tokens, and credentials are never stored or transmitted outside your browser.
  • Local Caching & Exports: Temporary 24-hour cache entries for DNS/IP/CVE lookups and your Dark/Light theme choice are stored locally in chrome.storage.local. JSON and CSV exports are generated locally and saved directly to your device.

3. Direct Public API Queries

To provide infrastructure and vulnerability intelligence without a middleman server, your browser queries three public APIs directly:

Feature Public Endpoint Data Sent
DNS Resolution (DoH) https://cloudflare-dns.com/dns-query Active tab's domain name only (e.g., example.com)
IP & ASN Intelligence https://ipwho.is/ Resolved public IPv4 address of the target server
CVE Vulnerability Audit https://api.osv.dev/v1/query Detected library name & version (e.g., jquery 3.6.0)

4. นโยบายความเป็นส่วนตัว (สรุปภาษาไทย)

  • ไม่เก็บข้อมูลส่วนบุคคล 100%: StackLens ทำงานแบบ Serverless บนเบราว์เซอร์ในเครื่องของคุณโดยตรง ไม่มีการเก็บประวัติการเข้าเว็บ (Browsing History) หรือส่งข้อมูลของผู้ใช้ไปยังเซิร์ฟเวอร์ของนักพัฒนา
  • ความปลอดภัยของข้อมูลและคุกกี้: การตรวจสอบ Cookies และ JWT เพื่อระบุระบบยืนยันตัวตน (เช่น Keycloak, NextAuth) จะอ่านเฉพาะชื่อคุกกี้และ URL ผู้ออกโทเค็น (iss) ในเครื่องเท่านั้น ไม่มีการบันทึกหรือส่งออกค่าโทเค็นลับออกไปภายนอก
  • การเชื่อมต่อ Public API มาตรฐาน: ข้อมูล DNS, IP และช่องโหว่ CVE จะถูกดึงโดยตรงจาก Cloudflare DoH (1.1.1.1), ipwho.is และ api.osv.dev โดยส่งเฉพาะชื่อโดเมนสาธารณะ เลข IP ของเว็บปลายทาง และชื่อไลบรารีเท่านั้น
